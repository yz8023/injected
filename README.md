# Injected - APK 弹窗注入工具

将自定义弹窗注入到任意 APK 的启动流程中，宿主启动时自动弹出弹窗。全部处理在本机完成：解析 Manifest → 定位启动类 → smali 插桩 → 重打包 → 重签名。

## 功能特性

### v2.1 增强
- **通用弹窗包格式适配**：社区弹窗包命名千差万别（smali.txt / 调用.txt / hook.smali / 说明.md / 中文 dex 名 / 嵌套 zip 变体），现在按内容智能识别（dex 魔数 + invoke 声明锚点），已验证 12 种主流社区包格式
- **一机一码（注册验证）**：可选注入激活验证门，宿主首次启动需输入激活码
  - 每次注入动态生成 RSA-2048 独立密钥对，公钥嵌入宿主，私钥导出保存
  - 机器码基于 ANDROID_ID，激活框支持长按复制，验证不可取消
  - 防绕过结构：原 onCreate 改名由验证门回调，删除 gate dex 原逻辑永不执行
  - 设置页内置注册机：粘贴私钥 + 机器码即可生成激活码
- **弹窗参数可视化编辑**：
  - 内置弹窗：标题/内容/按钮文字/倒计时秒数/跳转地址/外部关闭开关，表单编辑后实时重建
  - 外部弹窗包：文本声明文件直接编辑，保存后自动重打包
- **更新弹窗支持跳转**：更新提示的主按钮可绑定下载地址，点击拉起浏览器（异常自动 Toast）
- **入口自动识别**：已选弹窗列表显示自动解析的入口类#方法，预览页一键填入
- **上次选择记忆**：宿主 APK 与弹窗包选择状态跨会话恢复（本地缓存副本不受 SAF 授权失效影响）
- **手动预览**：弹窗包选择后改为手动点「预览」，多包管理（预览/编辑/移除）更顺手
- **闪退修复**：修复二次元公告弹窗在部分系统上的寄存器崩溃问题
- **片段级调度器**：随机触发支持多行 smali 片段弹窗包，分支级异常隔离

### v2 增强
- **多弹窗包注入**：一次选择多个弹窗包同时注入（SAF 多选，选择时自动缓存本地副本）
- **触发策略可选**：
  - 随机触发：注入随机调度器，宿主每次启动等概率弹出一个弹窗
  - 依次触发：全部弹窗按顺序插入启动流程，宿主启动时全部弹出
- **内置 8 种弹窗**：基础弹窗、多按钮弹窗、进度条弹窗、更新提示弹窗、倒计时公告、二次元公告（渐变背景）、列表弹窗、输入框弹窗，一键生成弹窗包无需外部文件
- **即时预览**：选择弹窗包后在注入器内试弹，预览效果所见即所得
- **双色主题**：浅色樱花粉紫 / 深色霓虹夜紫，跟随系统深色模式
- **assets 支持**：弹窗包可携带图片等资源，注入时自动合并进宿主 APK

### 核心能力
- 自动解析 APK 的 AndroidManifest（二进制 AXML），列出启动器 Activity 供选择
- baksmali 反编译目标 dex → 插桩 → smali 汇编，全流程使用 dexlib2
- 追加 dex 而非覆盖：多 dex 命名自动避开宿主现有编号
- 弹窗代码独立 try-catch，单个弹窗异常不影响宿主启动
- 重签名支持：内置 debug 签名，或导入自定义 keystore（JKS/BKS）
- 非 zip / 损坏条目容错：Windows 工具产出的非标弹窗包可自动跳过坏条目继续处理

## 使用方法

1. **选择宿主 APK**：注入目标（如 `com.heci.toolbox`）
2. **选择弹窗包**：从文件选择（支持多选）或从内置弹窗库勾选；列表中可预览、编辑参数、移除
3. **配置触发策略与一机一码**：随机/依次；需要注册验证时打开一机一码开关
4. **出击**：等待注入完成，产物输出到应用私有目录，安装即可
5. **（一机一码）**：注入完成后导出私钥；在宿主设备看到机器码后，用设置页注册机生成激活码

弹窗包为 zip 格式（以下内容按内容识别，文件名可变）：

```
*.dex            # 弹窗代码（编译后的 dex，支持任意文件名与嵌套变体）
*.txt / *.smali  # smali 调用声明（含 invoke 指令的文本，可多段调用点）
assets/          # 可选，图片等资源
popup.conf       # 可选，内置弹窗参数（Injector 生成）
```

## 构建

需要 JDK 17 与 Android SDK（compileSdk 34）：

```
./gradlew assembleDebug
```

国内网络可将 `gradle/wrapper/gradle-wrapper.properties` 中的 distributionUrl 替换为腾讯镜像：

```
distributionUrl=https\://mirrors.cloud.tencent.com/gradle/gradle-8.7-bin.zip
```

Maven 依赖已配置阿里云镜像（settings.gradle）。
